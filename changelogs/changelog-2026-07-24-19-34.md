# Changelog — 2026-07-24

## Changed

- **Bot status cycle** — Now rotates through 4 activities every 25 seconds: Playing Project Sekai, server count, owner, and GMT+7 datetime
- **Status page** — Replaced plain-text health server (port 8899) with Next.js status page (port 3995), dark monochrome design
- **`src/index.ts`** — Removed HTTP server; bot writes `status-data.json` for Next.js to consume
- **`Dockerfile`** — Now builds and runs both bot and Next.js; exposes port 3995

## Added

- **`app/`** — Next.js app directory with status page (`page.tsx`), API route (`api/status/route.ts`), and root layout
- **`next.config.ts`** — Next.js config with standalone output
- **`tsconfig.bot.json`** — Separated bot TypeScript config from root (used by Next.js)
- **`package.json`** — Added `next`, `react`, `react-dom`, `concurrently`; new scripts: `dev:bot`, `dev:status`, `dev`
- **`.gitignore`** — Added `status-data.json`, `.next/`

## Removed

- **Health server** (port 8899) — Replaced by Next.js status page on port 3995
