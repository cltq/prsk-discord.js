# Changelog — 2026-07-23

## Changed

- **Migrated** entire project from Python (discord.py) to TypeScript (discord.js 14)
- **Runtime** changed from Python 3.13 to Bun
- **TTS** changed from `edge-tts` (Python) to `node-edge-tts` (npm)
- **Voice** changed from `discord.py` voice to `@discordjs/voice`
- **Docker** base image changed to `oven/bun:latest`
- **Package name** changed from `sekaiutils-discord` to `prsk-discord.js`
- **Repository** moved from `cltq/sekaiutils-discord` to `cltq/prsk-discord.js`
- **`/auth`** renamed to **`/invite`** — removed secret key logic
- **`auto.sh`** — Replaced Node.js/npm with Bun; added `--install-systemd` and `--remove` flags; use `BASH_SOURCE[0]` for reliable CWD
- **`package.json`** — `start` script now runs `bun dist/index.js`
- **`prsk-discord.service`** — Added `EnvironmentFile` for `.env`; removed `ProtectHome=read-only`; added `ReadWritePaths` for `~/.bun` and `/tmp`

## Added

- **`src/deploy-commands.ts`** — Slash command registration script (`bun run deploy`)
- **`bun run dev`** — Hot-reload development mode via tsx
- **`bun run typecheck`** — TypeScript type checking
- **`src/types/index.ts`** — Shared TypeScript types (Command, GuildConfig)
- **`/changelog`** — Autocomplete support for changelog selection
- **`/songs`** — Paginated song list with prev/next buttons
- **`prsk-discord.service`** — Example systemd service file for Linux deployment
- **README.md** — Systemd installation instructions with required config fields

## Fixed

- Voice adapter type compatibility with `@discordjs/voice`
- Health check server now responds on first data read instead of parsing full HTTP request
- **`loadCommands`/`loadEvents`** — Skip `.d.ts` declaration files to prevent `ReferenceError: _default is not defined`
- **`src/index.ts`** — Load `.env` with explicit path via `path.join(__dirname, "..", ".env")` to fix auth failure under systemd
- **`prsk-discord.service`** — Removed `EnvironmentFile` to prevent conflict with dotenv (auto.sh already sources `.env`)
- **`auto.sh`** — Added `BOT_TOKEN` length validation before startup for faster error diagnosis
- **`prsk-discord.service`** — Switched from system to user systemd; removed hardcoded `User`/`Group` and root-only hardening; uses `%h` specifiers and `WantedBy=default.target`
- **`auto.sh --install-systemd`** — Now installs to `~/.config/systemd/user/`, enables linger, no root needed

## Removed

- All Python files (`bot.py`, `cogs/`, `utils/`, `requirements.txt`)
- `unused/` directory (archived admin commands)
- `auto.sh` Python venv logic (replaced with Bun)
